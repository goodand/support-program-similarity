# DB 텍스트 청크 기반 유사도 실험 (공개용 사본)

같은 목적(지원사업 유사도 검색·평가)의 실험 코드 사본입니다. 예산서 대신 사업정보 DB·CSV·엑셀의 표 행 텍스트를 이어 청크로 만들어 검색·군집(Leiden)을 평가합니다.

- 원본: 로컬 실험 폴더의 git 커밋 `2d1941c` (2026-10-28) 시점 코드·설정·문서입니다.
- 개인 PC 경로는 `<DEV_EVAL_ROOT>`로 바꿨습니다. 이 값과 폴더 밖 입력(DB, 모델, 파이썬 환경)을 맞추기 전에는 그대로 실행되지 않습니다. 원본 코드의 경로 정리(폴더 안은 상대경로, 폴더 밖은 설정값)는 이후에 반영합니다.
- 실제 DB·엑셀 사본, 청크, 벡터, 실행 결과와 로그는 포함하지 않습니다.
