# 사업 유사도 학습 전 EDA 노하우

## 평가 단위를 먼저 고정한다

35개 질의·14개 그룹·668개 공고를 사용한다. 질의 자신을 제외한 667개 후보에서 알려진 정답 30쌍(60방향)을 평가한다. 같은 질의의 여러 후보와 같은 그룹의 여러 질의는 독립 표본으로 세지 않는다. 질의별 마지막 정답 순위를 구한 뒤 그 최댓값을 보고한다. 8위는 학습된 임베딩이 달성한 기준선이다. 전체 MAP와 개선·악화 질의도 함께 본다.

## 일곱 분석의 적용 순서

|방법|이번 실행과 관찰|다음에 적용하는 법|
|---|---|---|
|8위 경계 역전|임베딩은 35/35, 기본 Decider는 31/35, 동일성 학습 후에는 29/35 질의에서 정답을 모두 8위 안에 회수했다. 최악 질의에서 알려진 정답은 임베딩 4위, 기본 15위, 학습 후 18위였다.|정답과 추월 후보를 연결해 순위 전후를 저장한다. 실패 6개와 성공 대조 6개를 익명 순서로 검토했다. 실패 6개에서 목적·활동은 미판정 후보가 높거나 동점이었고 수혜자는 기존 정답이 5개에서 높았다. 전체 후보의 오라벨률로 환산하지 않는다.|
|스피어만|각 질의의 667개 점수 순위를 비교한 중앙값은 임베딩 대비 기본 0.647, 학습 후 0.650이었다.|전체 순위가 비슷해도 최악 질의가 밀릴 수 있다. 질의별 마지막 정답 순위와 대조한다.|
|켄달 타우-b|두 모델 Top-15 합집합에서 각 후보 쌍의 순서를 대조했다. 질의별 중앙값은 기본 0.320, 학습 후 0.347이었다.|같은 후보 집합에서 양 모델 점수를 모두 읽고 동점을 반영한다. 역전 사례까지 보존한다.|
|로지스틱 회귀|기존 정답과 상위 미판정 후보의 비교 1,032개 중 기본 Decider와 임베딩의 선호가 갈린 사례는 87개였다. 14개 그룹을 하나씩 제외한 통합 균형 정확도는 0.717이었다.|입력 특성은 임베딩이 선호한 후보에서 다른 후보의 값을 뺀 값이다. 목적·활동·수혜자·제목의 문자 2-gram Jaccard, 기관 일치, 문서 길이 차이를 사용한다. 훈련 그룹 안에서만 표준화한다.|
|깊이 2 결정트리|같은 분할에서 균형 정확도 0.628. 14번 모두 첫 분기는 지원 내용의 어휘 겹침 차이였다.|첫 분기가 반복되는지와 숫자 기준이 안정적인지를 따로 본다. 분기점은 약 -0.017~0.036으로 흔들려 고정 임계값 채택은 보류한다.|
|구면 K-means|668개 임베딩을 24군집으로 나눴을 때 각 질의의 Top-8에서 가장 많이 등장한 군집의 점유 수 중앙값은 초기값 3개에서 각각 8, 8, 7개였다. 같은 군집에 든 정답 쌍은 각각 30, 26, 27쌍이었다.|한 군집의 후보만 뽑으면 학습쌍이 단조로워질 수 있다. 같은 군집 안에서 지원 활동이 다른 쌍과 군집 경계에서 활동이 비슷한 쌍을 별도 표집한다. 군집은 초기값과 군집 수에 의존한다.|
|피어슨|667개 후보의 코사인과 Decider 판정 점수 사이 질의별 상관 중앙값은 기본 0.760, 학습 후 0.767이었다.|선형 동행 여부를 본다. 정확한 점수 재현은 같은 척도로 맞춘 후 별도 오차로 검증한다.|

## 회귀 계수 해석

그룹별 훈련 분할에서 얻은 표준화 계수의 중앙값은 지원 내용 -3.762, 제목 -0.780, 수혜자 -0.686, 기관 +0.280, 목적 -0.096, 길이 차이 +0.006이었다. 지원 내용 계수의 부호는 다른 입력을 고정했을 때 임베딩 선호 후보의 활동 문구가 질의와 상대적으로 더 겹칠수록 기본 Decider도 같은 후보를 선호하는 방향과 연결된다는 뜻이다. 문자 겹침으로 의미 자체를 측정한 것은 아니다. 87개 역전 사례, 클래스 균형 가중치, 후보 선정 조건에 따라 계수 크기가 바뀔 수 있다. 이를 모델의 내부 가중치나 업무상 중요도로 쓰지 않는다.

## 다음 학습쌍을 고르는 법

평가 질의와 겹치지 않는 사업에서 같은 수혜자·다른 활동, 다른 수혜자·같은 활동, 둘 다 가까운 경우를 따로 모은다. 특히 문자 겹침이 낮아도 실제 활동이 같은 사례와 문구는 유사해도 활동이 다른 사례를 모두 포함한다. 같은 쌍에 임베딩 교사 점수를 부여하고, 미판정 후보를 자동 음성으로 바꾸지 않는다. 소표본 과적합으로 구현을 확인한 뒤 실제 35질의 전체 순위를 재평가한다. 이 표본 설계가 성능을 높이는지는 아직 미검증이다.
