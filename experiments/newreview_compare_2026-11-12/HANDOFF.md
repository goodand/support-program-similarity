# 인계: 다른 PC에서 이어서 할 일 (2026-11-12)

이 폴더의 결과를 이어받아 GPU가 없는 PC에서 작업하기 위한 안내다. 결과 요약은 `README.md`, 질의별 숫자는 `PER_QUERY.md`, 검증 기록은 `VERIFY_LOG.md`에 있다.

## 1. 지금까지 확정된 것

- **비교 조건 20가지** (668 풀, 질의 35개, 가장 나쁜 마지막 정답 순위): README 결과 표.
- **기준 임베딩 모델:** B3 설정 + 배치 128 + **5스텝 학습**. seed 4개(42·43·45·46)에서 청크 단독 8~9, 결합 8~9.
- **파인튜닝 효과:** 공고명만 입력에서는 질의 14개 개선, 어느 그룹을 빼도 개선 유지. 청크 입력에서는 개선이 G20 한 그룹에 기댐.
- **외부 평가자 대조 대상:** G20, G27, G23 (README "외부 평가자 결과와 대조할 그룹").
- **9칸 + 지원규모:** 개선 없음. 열 상관 분석: 열끼리 거의 독립(순위 상관 −0.13~0.26), 9칸에서 열을 빼면 내용 열의 손실이 가장 큼(8 → 14).

## 2. 이 PC(GPU 있음)에서만 할 수 있는 일

다른 PC에서는 진행하지 않는다. 필요하면 원래 PC에서 돌리고 결과 숫자만 이 폴더에 추가한다.

| 일 | 이유 |
|---|---|
| 새 텍스트 인코딩(공고명·청크·열 조합) | Qwen3-Embedding-8B + LoRA 어댑터, GPU 필요 |
| 파인튜닝 추가 학습(seed·학습량 변경) | GPU 필요 |
| 공고명 기준 결합(키워드+임베딩) 점수 | 공고명 임베딩은 있으나 결합 채점용 파이프라인 정리가 필요. 임베딩 파일이 원래 PC에 있음 |
| Decision Model 27B 남은 계산 | GPU 필요, 668행 중 138행까지 계산해 둠 |

## 3. 다른 PC에서 할 수 있는 일 (GPU 불필요)

1. **외부 평가자 결과 대조 (11-16 도착 예정):** `PER_QUERY.md`의 질의 행·짝 행·앞에 온 후보 행을 평가자 판정과 맞춘다.
   - 먼저 G20·G27·G23. "앞에 온 후보를 평가자도 비슷한 사업으로 보는가"를 센다.
   - 판정 기준(예: 앞에 온 후보 중 평가자가 비슷하다고 본 비율)은 결과를 보기 전에 정해 둔다.
2. **평가자 결과로 파인튜닝 효과 재확인:** 평가자가 새로 묶은 그룹을 질의로 쓰면 5스텝 설정을 고를 때 보지 않은 독립 검증이 된다. 이 계산은 임베딩 파일이 필요하므로, 질의·정답 목록을 정리해 원래 PC에서 채점한다.
3. **보고서 작성:** README 표와 아래 표기 규칙을 따른다.
   - "학습 후"는 "5스텝 학습(배치 128, 640쌍)"으로 쓰고, 평가셋을 보고 고른 설정임을 함께 적는다.
   - LLM 비용은 CLI 보고값 대신 토큰 수 × 공식 단가로 계산한다.
   - Decision Model 값(75, 27.5)은 별도 세션 보고값이다.

## 4. 공개하지 않은 입력 (원래 PC에만 있음)

아래 파일은 공고 마스터 시트(공유금지)의 목적·내용 원문이 들어 있어 이 저장소에 넣지 않았다. 다른 PC로 옮길지는 사용자가 정한다. 경로는 원래 PC의 `<원래 작업 폴더>/runs/044/` 기준이다.

| 파일 | 크기 | sha256 앞 16자 | 내용 |
|---|---|---|---|
| `pool668_newreview_harness/chunks.jsonl` | 600K | 227679212be3a64b | 공고 668개 청크(9칸 원문) |
| `pool668_newreview_harness/texts.json` | 396K | 649a57f7dd5ed6bd | 키 순서·평가 그룹 |
| `pool668_newreview_harness/eval_set_pool668.json` | 40K | 13285d447cf2b6b3 | 평가셋(그룹 14개·쌍 30개) |
| `pool668_newreview_harness/kiwi_tokens.json` | 568K | 6dbccd498ce6b576 | 키워드 점수용 토큰 |
| `pool668_newreview_harness/knn/knn_chunk_K30.npz` | 544K | e2cdedd9f7eabf79 | 군집용 이웃 그래프 |

임베딩 파일(`*_harness/*.npz`, 수십~수백 MB)은 원문에서 만든 값이라 함께 공개하지 않는다.

## 5. 스크립트 실행 환경

- `scripts/`의 스크립트는 원래 PC의 폴더 구조(`runs/044/...`)를 전제로 한다. 다른 PC에서는 위 입력을 같은 상대 경로에 두어야 한다.
- 환경변수: `WORKFLOW_RUNNER_DIR`(LLM 격리 호출용 어댑터), `ISO_CWD`(LLM 호출용 빈 폴더), `NOTICE_MASTER_XLSX`·`NOTICE_MASTER_SHEET_PREFIX`(열 분석용 마스터 시트).
- LLM 조건 재실행은 `claude` CLI 로그인이 필요하다. Fable 5.2는 CLI 2.1.290 이상이 필요하다(이번에는 쓰지 않기로 함).
- 순위 규칙: 점수 기반은 `scripts/eval_v3.py`의 `rank()`, LLM은 목록 위치(반복 번호는 첫 등장만).
