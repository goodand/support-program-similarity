# 임베딩 교사의 후보 순서를 학습한 Decider 파일럿

2026-11-25. 동일한 질의 안에서 임베딩 코사인 점수가 높은 후보의 Decider 원점수가 낮은 후보보다 커지도록 학습했다. BF16 Decider 27B 본체를 고정하고 기본 FP32 판독층의 false/true 두 행을 갱신했다. 각 공고 쌍의 원점수는 true 로짓에서 false 로짓을 뺀 값이다. 손실은 모든 질의 내 후보 비교의 softplus(낮은 쪽 원점수 − 높은 쪽 원점수) 평균이다.

## 표집과 학습

기존 668개 패널에서 평가 사업 35개를 질의·후보 양쪽에서 제외했다. 공백을 제거한 사업명도 검사했다. 32개 구현 점검 입력은 기준 사업 8개에 후보 4개씩이다. 기준 사업마다 후보 4개를 두 개씩 비교하면 6가지가 되어 총 48개의 순서 비교가 된다. 학습 전 34개에서 학습 후 48개 일치했다. 학습률 0.001로 50회 갱신했으며 저장한 판독층을 다시 읽어 동일함을 확인했다.

파일럿은 기본 판독층에서 새로 시작했다. 구현 점검에 쓰인 사업을 제외한 패널에서 시드 20261125로 기준 사업 80개를 비복원 추출해 64개는 학습, 16개는 교사 순서 검증에 사용했다. 각 기준 사업의 허용 후보에서 임베딩 순위 1·3·9·25위를 뽑았다. 학습률 0.0002로 전체 비교를 60회 갱신했다. 학습 384회 비교의 교사 일치 수는 299 → 333, 검증 96회 비교는 87 → 86이었다. 검증 기준 사업은 학습 양쪽에서 제외했으며 양쪽에 후보로만 등장한 사업은 17개다.
