## 결과와 해석
같은 35개 질의, 14개 그룹, 질의당 자기 자신을 제외한 667개 후보를 평가했다. 정답은 사전 판정한 30개 무방향 쌍이며 양방향으로 60건이다. 질의별 AP는 정답이 등장한 각 위치의 precision 평균, MAP는 35개 AP의 단순평균이다. 최악 순위는 모든 질의의 모든 정답 중 가장 뒤에 나온 위치다.

## 어떤 학습 신호가 유효했는가
동일사업 판별 정확도는 93.10%에서 93.66%로 올랐지만 검색 MAP는 하락했다. 순위학습은 학습 표본을 바꾼 다섯 번 모두 기본 Decider의 MAP를 넘었고 네 번 임베딩을 넘었다. 다섯 표본의 평균 MAP는 상대 순서 학습 0.7758, 교사 코사인 점수 직접 회귀 0.2092였다. 원 파일럿 표본에서 정상 순서 0.7974, 질의 안 순서를 섞은 대조군 10회 평균 0.0449였다. 이는 해당 표집과 손실 설정에서 교사 순서가 제공한 신호를 뒷받침한다. 모든 점수 증류 기법에 일반화할 수는 없다.

## 규모와 중단의 해석
본 학습은 원문 53,686건에서 대표 문서 15,062개를 만들고 14,806개 학습·256개 검증으로 분할했다. 질의당 후보 네 개의 상대 순서를 학습했다. 검증 1,536회 비교에서 교사와의 일치는 0·116·232·347단계에 각각 1,202·1,273·1,283·1,293건이었다. 학습은 463단계 중 350단계에서 중단됐다. 검증 손실로 선택한 347단계 모델을 평가했다. 1에폭 완료 모델이나 후보 8개 본 실험의 결과는 없다.

사용자가 보고한 이전 임베딩 대조학습에서도 소규모 파일럿의 검색 결과가 더 좋았다. 이 브랜치에서 쌍을 맞춰 다시 집계한 파일럿 대 확대 실험 수치는 Decider에 한정된다. 표본 구성, 최적화 단계와 자료량이 함께 변해 어느 요인이 차이를 만들었는지는 미확정이다.

## 입력과 평가 기준
전문가 비교표의 여덟 항목으로 입력을 바꾸자 질의별 AP는 개선 2·동일 24·하락 9였다. 규모상세·부처 추가, 분류·대상유형 제거, 항목명과 순서 변경이 동시에 이뤄졌다. 규모상세 단독 효과는 분리되지 않았다.

질의 513에서 표준사업장은 임베딩 4위, 347단계 14위였으나 전문가 점수는 3.7이었다. 두 모델 1위인 보조공학기기 지원은 7.2였다. 창업교육은 347단계 3위였고 이 후보의 전문가 점수는 미확인이다. 창업교육과 표준사업장의 모델 점수 차이는 원문 +1.576, 수혜자 가림 +1.067, 기관 가림 +1.325, 제목 가림 −0.782였다. 기준 사업과 두 후보의 해당 필드를 동시에 가렸다. 이 한 사례에서 제목이 선후에 영향을 주었으나 어느 문구가 원인인지는 분리하지 못했다.

전문가 7점 이상으로 식별된 9건을 추가하면 MAP는 임베딩 0.8115, 기본 Decider 0.7902, 파일럿 0.8662, 347단계 0.8372였다. 검토 후보는 임베딩 상위권에서 골랐다. 사전 정답 30쌍은 과거 교사 평가에도 사용되었다. 고정 패널 결과를 새 공고의 성능 또는 독립적인 인간 선호도 비교로 확대 해석하기 어렵다.

## 운영 판단
신규사업 선례의 누락을 줄이는 목적에는 현 임베딩을 기본으로 둔다. 평균 검색 품질에는 순위학습 파일럿이 유력하다. 예산 군집화는 비교할 사업 묶음을 찾는 용도이고 실제 예산 절감은 측정하지 않았다. 학습 중단 직접 원인도 확정되지 않았다. 채팅 훅에는 이전 전달 권한 오류와 감시 종료시각 경과가 있었으며 GPU 재시작과 채팅 전달은 별도 사건이다.
