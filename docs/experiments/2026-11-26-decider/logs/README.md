# 다음 PC에서 실험 기록 읽기

세 JSON은 outputs 아래 상대 경로를 키로 사용한다. sources.tsv에는 수집한 원본 파일의 해시가 있다. 학습 스텝, 검증, 종료 상태, 설정, 통제 실험과 평가 기록에서 수치와 안전한 상태값을 추출했다. 자유 텍스트, 경로 및 원문은 생략될 수 있어 원본 로그의 바이트 단위 복사본으로 사용하지 않는다. experiments.tsv는 정제된 행 형태로 해당 JSON에 포함된다.

동일사업 smoke·파일럿은 decider_identity_v1.json, 구간별 실험은 decider_section_v2.json, 순위학습과 347단계 본 실험은 decider_18h_20261124.json에 있다. 이전 폴더의 README 및 query_metrics.csv에서 모델 간 비교를 확인한다. 동봉한 Python은 당시 판독층 학습·평가 구현 참조용이다. 실행에는 별도의 모델, 캐시, 원자료와 환경이 필요하며 중단된 학습을 복구할 체크포인트는 이 저장소에 포함되지 않는다.
